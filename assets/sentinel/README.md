# Jason Sentinel application identity

Name: Jason Sentinel (short name: Sentinel). The guardian shield uses a midnight navy background with cyan and azure highlights. The original artwork was generated for this project; raster exports preserve its proportions and safe padding.

- `logo-original.png`: original artwork.
- `icon-192.png`, `icon-512.png`: installation and browser icons.
- `src/assets/sentinel-icons.js`: embedded public PNG resources for the existing Worker router; the maskable icon uses the same padded 512px artwork.

The visual identity and PWA assets do not change the Telegram bot's username, profile, group settings, authentication or broadcast behavior.
