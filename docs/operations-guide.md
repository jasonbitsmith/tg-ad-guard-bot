# 运营闭环使用说明（2.15.0）

## 漏拦广告

管理员回复广告消息发送 `/漏拦`（或 `/missed`）。机器人提交删除和永久封禁任务，加入联防的来源群会同步到关联群。提示「已提交」表示任务已保存；在「处罚执行」核对真实结果。普通群友使用 `/report`，需管理员复核后处罚。

后台「漏拦广告上报」查看正文、成员、消息和话题。图片只保存 Telegram 图片指纹，不下载原图。存档保留 90 天，每群最多 300 条，界面展示最新 100 条。进入已有「全局样本库」，先预览正常案例的命中，再启用样本。待审核样本不自动处罚。

## 执行失败

「群防状态总览」优先展示缺少删消息/封禁权限、失败任务和逾期队列的群。「管理这个群」打开本群设置及执行结果。接收时间不是完整投递证明。

「处罚执行」分别显示删除、封禁、提示及联防提交。删消息失败仍尝试封禁；临时网络错误自动重试，达到现有限制后显示失败。修复权限后点击「重试未完成步骤」。已完成步骤保留进度，不因重试再次处罚。联防目标的实际结果在已有「联防执行与误封纠错」查看。

## 成员恢复

输入数字用户 ID 或机器人记录过的 @用户名，查看本机器人记录的封禁群。找不到用户名，请成员私聊发送 `/myid` 提供数字 ID。

「仅解封这个群」提交解封并信任该成员，防止再次联防封回。撤销联防需确认，会停用关联样本、取消关联待执行任务，并按封禁所有权恢复；后续其他处罚覆盖的封禁不自动撤销。只提交任务，不宣称已经执行；到处罚执行核对。尚未完成验证的成员继续使用已有「成员验证与解封」。

## 规则回放

先在人工确认案例库录入正常/广告案例。回放新关键词或黑名单域名，查看广告命中和正常误命中；不会保存规则或处罚成员。样本不足不代表无误报。上线前可沿用已有试运行，上线后可以回滚规则版本或停用样本。

## 轰炸应急

选群开启 5–120 分钟的临时防护。限制近两小时加入成员的媒体与链接；原入群验证关闭时临时启用按钮验证，现有更强验证保持不变。明确广告照常删除封禁，不仅凭链接或图片封号。

自动触发沿用本群防轰炸开关、阈值和时长；五分钟内不同账号发布明确广告也纳入触发。停止后五分钟不自动重开，到期自动失效，不改长期策略。到期前已经启动的验证仍需按提示完成。

## 邀请来源

仅统计新版实际收到的 Telegram 入群申请/成员加入事件；须事件带邀请链接。保存链接名称及哈希，不保存原地址。广告账号和验证失败分别统计，不能把验证失败当广告。机器人必须有相应管理权限并接收入群事件。需要关闭来源时，在 Telegram 撤销该邀请链接。

## 验证范围

本地模拟覆盖：漏拦授权及话题、待审核样本、正常重复讨论、删除失败仍封禁、步骤重试、应急开关/过期/申请验证、邀请去重和隐私、回放无副作用、联防撤销所有权及信任成员、全群状态。测试不向真实群发送广告或封禁真实成员。
